# Checkpoint 1 - Tools Agent

## Proyecto
Agente de Triaje de Soporte Técnico desarrollado en n8n.

## Flujo
- Chat Trigger
- AI Agent
- Anthropic Chat Model
- Herramienta Google Sheets: Registrar_Ticket_Soporte
- Gmail para observabilidad de la ejecución

## Herramienta de registro
El agente registra los casos de soporte en Google Sheets cuando cuenta con los datos mínimos necesarios.
